# Dylan Canada — CS 499 ePortfolio

This repository hosts a GitHub Pages portfolio for the CS 499 Computer Science Capstone. It uses one CS 360 Android Inventory App artifact to demonstrate growth in:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

The homepage contains the Professional Self-Assessment. Dedicated pages contain the code-review overview, original/enhanced artifact comparison, and readable enhancement narratives.
